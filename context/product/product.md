# SentriGate — Product Overview

## One-Line Definition

SentriGate is a security system for your websites that protects them from harmful attacks, malicious traffic, hackers, and anything that could cause your site to break, go offline, or lose data.

## Elevator Pitch

SentriGate is a modern origin protection and optimization platform designed to protect websites, APIs, and applications from cyber threats, abusive bots, and performance bottlenecks. Unlike traditional plugins tied to a specific framework, SentriGate operates at the HTTP layer — making it universally compatible with any backend technology.

## What SentriGate Is (Simple Language)

- The digital guard of your website
- An intelligent alarm that sees every threat before it reaches you
- Security that works automatically, without you needing to understand the technology

## The Result for Users

- A safer, more resilient website
- Less stress and worry about attacks or downtime
- Automatic, intelligent protection running 24/7

## Core Capabilities

| Capability | Description |
|---|---|
| Reverse Proxying | Routes traffic through SentriGate before reaching your origin |
| Intelligent Caching | Reduces backend load by serving cached responses at the edge |
| Form & Bot Protection | Blocks bots from abusing forms, logins, and APIs |
| Request Risk Scoring | Every request is scored for threat level in real time |
| JS Challenge Integration | Browser validation to stop non-human traffic |
| Edge Protection | DDoS, flood, and volumetric attack absorption |
| Centralized Analytics | Full visibility into traffic, attacks, and blocked requests |
| Origin Shielding | Your real server is never directly exposed |
| WAF | Blocks known attack patterns before they reach your app |

## Universal Compatibility

SentriGate is framework-agnostic. It works at the HTTP layer and requires no code changes to your application.

### Supported Platforms

- PHP applications
- WordPress
- Laravel
- Symfony
- Node.js
- Python frameworks (Django, Flask, FastAPI)
- Java applications (Spring Boot, etc.)
- Ruby applications (Rails, etc.)
- .NET applications
- Custom HTTP services

## Target Audience

### Primary
- Developers and DevOps engineers running VPS or dedicated servers
- Agencies managing multiple client websites
- SaaS companies protecting their APIs

### Secondary
- Small business owners using shared hosting (limited feature set)
- Enterprise IT teams needing an extra security layer on top of existing CDNs

## Competitive Positioning

SentriGate is not a Cloudflare replacement — it is a complement to it. When used alongside Cloudflare or any CDN, SentriGate adds an intelligent AI-driven layer of behavioral analysis, advanced reporting, and origin-level protection that generic CDN tools cannot provide.
